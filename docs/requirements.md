# POSCAP DEMパラメータ同定自動化システム 要件定義書

- 文書版: Draft 0.1
- 作成日: 2026-08-17
- 参照資料: `POSCAP_DEMパラメータ同定手順書_v1.4_20260803.docx`

## 1. 文書の目的

本書は、POSCAP素子成形シミュレーションで使用するDEMパラメータについて、実験データとAnsys Rockyによるシミュレーション結果を用いて同定する一連の処理を自動化するシステムの要件を定義する。

本システムでは、以下のパラメータを同定対象とする。

- 粉間転がり抵抗
- 粉間動摩擦係数
- 粉間静止摩擦係数
- 壁面動摩擦係数
- 壁面静止摩擦係数

パラメータ同定は、以下の3フェーズで構成する。

1. 粒度分布データの作成
2. せん断試験および安息角試験による粉体特性の同定
3. 壁面摩擦試験による壁面摩擦特性の同定

---

## 2. 背景

現在のパラメータ同定作業では、以下の操作を手動で実施している。

- 実験データのExcel処理
- 粒度分布データのDEM入力形式への変換
- Rockyプロジェクトの複製および設定変更
- 複数条件のRockyシミュレーション実行
- シミュレーション間の粒子座標の受け渡し
- Rocky結果のCSV出力
- トルクからせん断応力への変換
- 定常値および回帰直線の算出
- 応答曲面作成用CSVの作成
- Pythonスクリプトによる応答曲面の作成
- せん断試験と安息角試験の結果の重ね合わせ
- 交点からのパラメータ決定
- 壁面摩擦係数の補間計算

特にせん断試験では、1条件につき「充填、プリせん断、3 kPa本せん断、5 kPa本せん断、7 kPa本せん断」を順番に実行し、この処理を9条件について繰り返す必要がある。各工程では、粒子座標CSV、せん断セル高さ、トルク時系列データを次工程へ正しく引き渡す必要がある。

これらの作業は処理量が多く、設定間違い、ファイルの取り違え、転記ミスが発生する可能性がある。そのため、入力条件の検証、Rockyの実行、結果処理、パラメータ決定までを一貫して管理できる仕組みを構築する。

---

## 3. システムの目的

### 3.1 主目的

入力された実験データ、粒度分布、Rockyテンプレートおよび解析条件をもとに、DEMシミュレーションを自動実行し、実験値を再現するDEMパラメータを出力する。

### 3.2 副目的

- 手作業によるRocky設定変更を削減する
- シミュレーション条件の設定ミスを防止する
- 条件と結果の対応関係を追跡可能にする
- シミュレーションの中断および再開を可能にする
- 入力値、計算条件、結果、エラーを記録する
- Excelへの手作業による貼り付けを削減する
- 将来的なベイズ最適化への拡張を可能にする
- 異なる粉体への適用時に設定を変更できる構造とする

## 4. 適用範囲

### 4.1 自動化対象

#### フェーズ0

- 粒度分布データの読込み
- 粒子径と累積質量パーセントの形式チェック
- Rocky入力用粒度分布への変換
- 単位変換
- 変換結果のCSV出力

#### フェーズ1

- せん断試験の実験値の読み込み
- 実験定常傾きの計算
- 実験ピーク比の計算
- 安息角実験値の読み込み
- 3水準、2因子、9条件の自動生成
- せん断試験シミュレーションの自動実行
- 安息角シミュレーションの自動実行
- 結果CSVの自動取得
- 定常せん断応力の計算
- 定常傾きの計算
- 補正係数の適用
- 安息角の計算
- 応答曲面の作成
- せん断試験と安息角試験の目標線の算出
- 両方の実験値を満たす交点の算出
- 粉体パラメータの決定

#### フェーズ2

- 壁面摩擦試験の実験値の読み込み
- 実験定常傾きおよびピーク比の計算
- 3条件の壁面摩擦係数の生成
- 壁面摩擦シミュレーションの自動実行
- 結果CSVの自動取得
- 定常せん断応力および定常傾きの計算
- 補正係数の適用
- 線形補間による壁面摩擦係数の決定

### 4.2 自動化対象外

第1版では以下を対象外とする。

- FT4 Powder Rheometerの制御
- 粒度分布測定装置の制御
- 安息角実験の実施
- Rocky形状モデルの新規作成
- Rockyテンプレート内のジオメトリ変更
- 補正係数そのものの自動推定
- 微粉カット範囲の自動決定
- シミュレーション結果の物理的妥当性の最終判断
- パラメータ同定結果の無条件な確定

## 5. 前提条件および制約

### 5.1 手順上の前提

- せん断試験および壁面摩擦試験の破壊包絡線の切片を0とみなせる
- せん断試験のプリせん断でピークが得られる
- 壁面摩擦試験の本せん断でピークが得られる
- 実験値があらかじめ設定された探索範囲内で再現可能である
- 補正係数は粒度分布によらないものとして扱う
- 微粉カットの影響は未評価であり、現時点では入力データをそのまま利用する
- 微粉カットの要否および条件は人が事前に確定し、システムはカット適用済みの粒度分布を入力として受け取る(カット処理自体はシステムで行わない)

前提から外れる場合、システムは自動確定せず、警告を表示してユーザー判断を求める。

### 5.2 ソフトウェア

- Windows
- Python 3.11を基本候補とする
- Ansys Rocky
- PyRocky
- GitHub Copilot Agent
- Visual Studio Code
- pandas
- numpy
- scipy
- matplotlib
- openpyxl

### 5.3 対応Rockyバージョン

第1版ではAnsys Rocky 2025 R2のみを対象とする。他バージョン(2025 R1、2026 R1等)への対応は将来拡張とし、第1版のスコープには含めない。

Rockyバージョンは設定ファイルで指定し、"2025R2"以外が指定された場合は処理開始前にエラーとする。

## 9. 機能要件

### FR-01 プロジェクト作成

案件ごとに作業プロジェクトを作成し、案件ID、粉体名、作成日時、Rockyバージョン、テンプレート、入力、結果保存先、設定、実行状態を記録する。既存フォルダを自動上書きしない。

### FR-02 入力ファイル検証

実行前に以下を検証する。

- 必須ファイルの存在と読取り可否
- 出力先の書込み可否
- 粒子径が正の値であること
- 累積質量%が単調増加し、上限が100であること
- 摩擦係数および転がり抵抗が負でないこと
- Rocky.exeとテンプレートが存在すること
- 接続ポートが設定されていること
- 既存Rockyプロセスとの競合がないこと
- 指定されたRockyバージョンがシステムの対応対象であること
- 必要なTime Plot、Cross Plot、User Process、Geometryが存在すること

不備がある場合はRockyを起動しない。

### FR-03 粒度分布変換

- 入力列の特定
- 単位統一
- 並び替え
- 累積分布検証
- 必要に応じた最大径・最小径の設定
- Rocky入力形式への変換
- 変換前後データとグラフの保存

最大径または最小径を補完する場合はユーザー確認を求める。

### FR-04 実験せん断データ解析

#### 定常傾き

- 各本せん断テストの定常区間を抽出する
- Normal StressとShear Stressの平均値を求める
- 複数荷重の代表点に切片0固定の線形回帰を行う
- 傾きと確認用指標を保存する

#### ピーク比

- 2回目以降のPre-Shearを対象とする
- 定常時およびピーク時のShear/Normalを計算する
- `(ピーク時Shear/Normal) / (定常時Shear/Normal)` を求める
- 対象Pre-Shearの平均をピーク比とする
- 1回目のPre-Shearは使用しない

### FR-05 フェーズ1条件生成

以下の2因子を各3水準で組み合わせ、9条件を生成する。

- 転がり抵抗: 0.2、0.45、0.7
- 粉間動摩擦係数: 0.2、0.45、0.7

```text
粉間静止摩擦係数
= 粉間動摩擦係数 × せん断試験の実験ピーク比
```

水準値は設定ファイルから変更可能とする。

### FR-06 Rockyテンプレート管理

テンプレート原本を直接変更せず、案件・条件ごとにコピーして使用する。

- せん断: 粒子発生、充填、プリせん断、本せん断3/5/7 kPa
- 安息角: 安息角試験
- 壁面摩擦: 充填、プリせん断、本せん断3/5/7 kPa

### FR-07 粒子発生シミュレーション

1. テンプレート複製
2. DEM用粒度分布設定
3. Solver条件設定
4. シミュレーション実行
5. 正常終了確認
6. 時刻0秒の20度範囲内粒子の座標・粒子径取得
7. Particle Custom Inlet形式へ変換
8. 結果保存

### FR-08 Particle Custom Inlet CSV変換

Rocky出力を以下の形式へ変換する。

```csv
x,y,z,size
0.000599,0.032000,0.002970,0.0000879
```

以下を検証する。

- 必須列の存在
- 数値形式
- sizeが正
- 欠損なし
- 粒子数が0でない
- 単位がメートル
- 粗視化倍率の扱いが設定と一致

### FR-09 せん断試験シミュレーション

各9条件について、次を順番に実行する。

#### 充填

- 粉体パラメータとParticle Custom Inletを設定
- 実行後、最終時刻の底から1 ml範囲の粒子座標・粒子径を出力
- 次工程用CSVへ変換

#### プリせん断

- 粉体パラメータと充填結果CSVを設定
- 実行後、せん断セル高さと粒子座標・粒子径を出力
- 次工程用CSVへ変換

#### 本せん断

3、5、7 kPaごとに以下を実行する。

- 粉体パラメータ設定
- プリせん断結果CSV設定
- せん断セル高さ設定
- シミュレーション実行
- トルク時系列取得・保存

### FR-10 せん断試験結果解析

- トルクをせん断応力へ変換する
- 各荷重について0.501から0.55秒を標準の定常区間として平均する
- 3、5、7 kPaの結果に切片0固定の線形回帰を行う
- シミュレーション定常傾きを求める
- 補正係数を適用する
- 補正前後を保存する

```text
補正後定常傾き
= シミュレーション定常傾き × 補正係数
```

### FR-11 安息角シミュレーション

フェーズ1と同じ9条件について以下を行う。

1. テンプレート複製
2. 粒度分布設定
3. 粉体パラメータ設定
4. Solver条件設定
5. シミュレーション実行
6. Rockyバージョンに対応した解析処理
7. 安息角計算用データ取得
8. 安息角算出
9. 条件別結果保存

### FR-12 応答曲面作成

- 9条件の説明変数と目的変数を集約する
- 応答曲面モデルを構築する
- モデル式を保存する
- 実験目標値を満たす等値線を計算する
- CSVおよび画像を出力する
- 外挿の有無を記録する

説明変数:

- X1: 転がり抵抗
- X2: 粉間動摩擦係数

目的変数:

- せん断試験: 補正後定常傾き
- 安息角試験: 安息角

### FR-13 粉体パラメータ候補算出

せん断試験と安息角試験の目標等値線の交点を算出し、各候補について以下を出力する。

- 転がり抵抗
- 粉間動摩擦係数
- 粉間静止摩擦係数
- せん断試験予測値
- 安息角予測値
- 各実験値との差
- 探索範囲内か
- 境界近傍か

交点が複数存在する場合は自動確定しない。

### FR-14a 実行前確認

シミュレーション条件を初めて実行する前に、生成された条件表と実行計画をユーザーへ提示し、実行の承認を得る。承認前はRockyを起動しない。

### FR-14 フェーズ1結果確認

フェーズ2実行前に以下を確認できるようにする。

- 応答曲面
- 等値線
- 交点候補
- 実験値との差
- 条件別結果
- エラー・警告
- 同定候補
- 探索範囲内か

### FR-15 壁面摩擦実験データ解析

- 定常区間のNormal StressとShear Stressを平均する
- 切片を固定しない線形回帰により定常傾きを算出する
- 各テストの最大Shear Stressと同時刻のNormal Stressを取得する
- 切片0固定回帰でピーク傾きを算出する
- `ピーク傾き / 定常傾き` を壁面摩擦ピーク比とする

壁面摩擦ピーク比は第1版では参考値として記録するのみとし、壁面静止摩擦係数の算出には使用しない(FR-19参照)。

### FR-16 壁面摩擦条件生成

```text
条件1 = 実験定常傾き × 0.5
条件2 = 実験定常傾き × 1.0
条件3 = 実験定常傾き × 1.5
```

壁面静止摩擦係数は標準では壁面動摩擦係数と同値とする。倍率は設定変更可能とする。

### FR-17 壁面摩擦シミュレーション

フェーズ1で決定した粉体パラメータを使用する。

- 充填を実行し、次工程用粒子CSVを作成する
- 各壁面摩擦条件でプリせん断を実行する
- 壁面摩擦ディスク高さと粒子CSVを取得する
- 3、5、7 kPaごとに本せん断を実行する
- トルク時系列を取得する

### FR-18 壁面摩擦結果解析

- 0.201から0.25秒を標準定常区間として平均する
- 3、5、7 kPaの関係に切片を固定しない線形回帰を行う
- 定常傾きを算出する
- 補正係数を適用し、補正前後を保存する

### FR-19 壁面摩擦係数決定

条件1-2間および条件2-3間を線形補間し、補正後定常傾きが実験定常傾きと一致する壁面動摩擦係数を算出する。実験値が3条件の結果範囲に含まれない場合は外挿せず、探索範囲不足として警告する。

壁面静止摩擦係数は、標準設定では壁面動摩擦係数と同値とする。倍率は設定ファイルで変更可能とする。

### FR-20 実行状態管理

```text

REVIEW_REQUIRED
```

条件単位および工程単位で状態を保存する。

### FR-21 中断・再開

失敗した工程から再開できること。再開前に前工程のファイル、必要列、正常終了、パラメータ一致、テンプレート・入力変更の有無を確認する。入力条件変更時は依存する後続工程を無効化する。

### FR-22 エラー処理

## 10. 非機能要件

### NFR-01 再現性

同一入力、テンプレート、Rockyバージョン、計算設定から同等の実行手順を再現できること。乱数や初期配置に関する設定も保存する。

### NFR-02 追跡可能性

```text
最終パラメータ
→ 補間または交点
→ 応答曲面
→ 条件別解析結果
→ Rocky出力
→ Rocky入力条件
→ 実験入力
```

### NFR-03 安全性

- テンプレート原本を変更しない
- 既存結果を自動上書きしない
- Delete Results相当処理を無許可で実行しない
- 入力を自動削除しない
- 条件変更時は影響範囲を表示する
- フェーズ1確定前にフェーズ2を実行しない

### NFR-04 保守性

- Rocky操作と解析処理を分離する
- 試験別にモジュールを分離する
- 数値条件は設定ファイルで管理する
- Rockyバージョン依存処理をアダプタとして分離する
- Excelに依存しない計算ロジックを持つ
- 既存Excelとの比較機能を用意する

### NFR-05 拡張性

- 水準値・条件数変更
- 追加パラメータ同定
- ベイズ最適化
- 過去データによる初期点設定
- 類似粉体検索
- ばらつき評価
- 複数Rockyバージョン対応
- GUIまたはWeb UI
- 自然言語実行指示

### NFR-06 操作性

自然言語は構造化設定への入口として使用し、Rocky実行前に実行計画を表示する。

## 13. 第1版の開発範囲

第1版は以下の順で段階的に進める。

6. 充填からプリせん断へのデータ引継ぎ
7. プリせん断から本せん断へのデータ引継ぎ

## 14. 受入基準

### AC-01 条件生成

ピーク比を入力したとき、9条件について正しい転がり抵抗、動摩擦係数、静止摩擦係数が生成されること。

### AC-02 CSV変換

既存Rocky出力CSVから、手作業で作成したParticle Custom Inlet CSVと同じ列・数値が生成されること。

### AC-03 せん断1条件

```text
充填
→ 粒子CSV取得
→ プリせん断
→ セル高さ取得
→ 粒子CSV取得
→ 3、5、7 kPa本せん断
→ トルク取得
→ 定常傾き算出
```

上記が人の操作なしで完了すること。

### AC-04 数値一致

既存解析Excelと比較し、以下が設定した許容差内で一致すること。

- せん断応力
- 本せん断シミュレーション結果のラスト0.05秒平均(定常区間0.501–0.55秒に対応)
- 3点回帰傾き
- 補正後定常傾き
- 安息角
- 応答曲面予測値
- 交点
- 壁面摩擦係数

### AC-05 再開

5 kPa本せん断で失敗した場合、充填、プリせん断、3 kPa本せん断を再実行せず、5 kPaから再開できること。

### AC-06 安全性

- テンプレート原本が変更されない
- 既存結果が意図せず削除されない
- 同名案件が意図せず上書きされない
- エラー時にも完了済みデータが保持される
